# SolidPing has no Fly.io installation guide

## Problem
`web/docs/docs/installation/` documents Docker, Kubernetes, Railway, Coolify and others, but not Fly.io.

## Proposal
1. Add `web/docs/docs/installation/fly-io.md` (sidebar position 10, same shape as `railway.md`): deploy the published image with SQLite on a volume at `/data`, health check on `/api/mgmt/health`, first login, switch to Postgres, upgrading.
2. Add `deploy/fly/fly.toml` and `deploy/fly/Dockerfile` (`FROM ghcr.io/fclairamb/solidping:0.38`, `USER 0`): the image runs as uid 65532 and Fly volumes are not documented as writable by it, so the wrapper runs as root like Railway's `RAILWAY_RUN_UID=0`.
3. Link the page from the installation list where Railway is mentioned (grep `railway` in `web/docs` and `README.md`).

## Tests
- `cd web/docs && bun run build` passes (no broken links).
- `fly.toml` parses as TOML.

## To verify
- Volume ownership on Fly for a non-root image was not confirmed in Fly's docs; the root wrapper avoids the question. The deploy was not run against a real Fly account.
