# Uptime Monitoring Services Comparison

Comprehensive comparison of uptime monitoring services for the SolidPing project.

This directory replaces the previous monolithic `competitors/comparison.md` (598
lines) and re-organizes the material per the size rule in `../../CLAUDE.md`.
Content is unchanged — only the file layout is.

## Files in this directory

- [overview.md](overview.md) — At-a-glance matrix across 7 uptime-first competitors, pointers to the adjacent analyses (Site24x7, Maintenant), where SolidPing stands today, and the **2026-07 refresh** of pricing, releases and market moves (Freshping shutdown, Uptime Kuma 2.x, per-vendor pricing deltas).
- [pricing.md](pricing.md) — Free tier, entry-level paid, mid-tier, and value-at-100-monitors tables, with a winner per bracket.
- [monitor-types.md](monitor-types.md) — Check-type matrix across 9 tools (HTTP through game servers, email inbox and custom JS), plus who is most comprehensive / most flexible.
- [api.md](api.md) — Authentication, API design, rate limits, and available endpoints for BetterStack / UptimeRobot / Pingdom.
- [features.md](features.md) — Monitoring capabilities, alerting & notification channels (per-tool matrix), advanced features, and developer experience.
- [pros-cons.md](pros-cons.md) — Pros, cons and "best for" verdicts for BetterStack, UptimeRobot and Pingdom.
- [use-cases.md](use-cases.md) — What to learn from and what to avoid per vendor, plus a recommendation per user type.
- [solidping-position.md](solidping-position.md) — SolidPing's advantages, the Tier 1/2/3 feature inventory (✅ shipped, ❌ gaps), unique strengths vs. the closest competitor, and a SaaS pricing-strategy proposal.
- [verdict.md](verdict.md) — Summary comparison table and the final winner-by-category verdict.
